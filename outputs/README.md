# Analysis outputs

The files in this directory are the reference results generated by `python replication/run_all.py`. The replication runner regenerates and validates 20 expected files. GitHub Actions checks that a fresh run produces the same committed results.

## Tables

- `tables/descriptive_statistics.csv`: descriptive statistics for the three series in the 438-observation complete-case sample.
- `tables/correlation_matrix.csv`: pairwise correlations among the three series.
- `tables/fitted_values.csv`: actual industrial production, fitted values, and residuals for the baseline regression.
- `tables/baseline_coefficients.csv`: baseline OLS coefficients with HC1 standard errors and confidence intervals.
- `tables/baseline_regression_summary.txt`: baseline regression summary.
- `tables/missing_data_report.csv`: dates and series with missing observations.
- `tables/complete_monthly_segments.csv`: uninterrupted complete monthly segments.
- `tables/inference_comparison.csv`: HC1 and HAC(12) inference comparisons across the full and uninterrupted samples.
- `tables/diagnostic_tests.csv`: Rainbow, Breusch–Pagan, and Durbin–Watson results.
- `tables/ljung_box_tests.csv`: Ljung–Box residual autocorrelation tests at lags 6 and 12.
- `tables/variance_inflation_factors.csv`: variance inflation factors for the two baseline regressors.
- `tables/stationarity_tests.csv`: ADF and KPSS results for level and transformed series.
- `tables/cointegration_test_decision.csv`: the conditional decision on whether the standard Engle–Granger test is reported.
- `tables/changes_model_coefficients_hac12.csv`: supplementary monthly-change model coefficients with HAC(12) inference.

## Figures

- `figures/macro_series.png`: the three monthly macroeconomic series.
- `figures/actual_vs_fitted.png`: actual and fitted industrial production from the baseline levels regression.
- `figures/partial_regression_fedfunds.png`: partial-regression plot for the federal funds rate, conditional on unemployment.

## Diagnostic reports

- `diagnostics/contiguous_levels_hac12_summary.txt`: HAC(12) summary for the levels regression on the 429-month uninterrupted sample.
- `diagnostics/changes_model_hac12_summary.txt`: HAC(12) summary for the supplementary monthly-change model.
- `diagnostics/reproducibility_manifest.json`: input hash, sample dates, missing observations, software versions, and supplementary-model sample information.

These are computational results, not causal estimates. See [the methodology notes](../docs/METHODOLOGY.md) for the model choices and interpretation limits.
